**Release Date**: August 29, 2025

## 🐛 Issue Fixed

### **Missing ActionID 2 Mapping**
- **Problem**: ActionID 2 showed as "technique_name ActionID_2 fundamental technique unknown"
- **Root Cause**: ActionID 2 missing from `instrument_actionid_mappings` database table
- **User Impact**: CC-CV technique files displayed with unknown classification

## 🔧 Technical Solution

### **Database Mapping Addition**
```sql
INSERT INTO instrument_actionid_mappings 
(action_id, action_name, technique_id, description) 
VALUES (2, 'CC-CV', 2, 'Constant Current - Constant Voltage technique mapped to Galvanostatic')
```

### **Mapping Details**
- **ActionID**: 2
- **Action Name**: CC-CV
- **Fundamental Technique**: Galvanostatic (technique_id 2) 
- **Category**: Constant current technique classification
